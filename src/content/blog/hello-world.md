## Writing a new post

Create a new file in `src/content/blog/`, for example `my-first-real-post.md`, and start it with a small header:

```md
---
title: "My first real post"
description: "One sentence summary."
date: 2026-12-01
tags: ["notes"]
---

Write your post here in plain Markdown.
```

That's it. The file name becomes the URL (`/blog/my-first-real-post/`).

> Tip: add `draft: true` to the header to hide a post until it's ready.
